# BananaForge 0.3.21

## Fixes

- First-run MelonLoader IL2CPP assembly generation is tracked as part of launch instead of reporting success while BTD6 is still preparing.
- Play remains locked during generation so users do not accidentally start a duplicate game process.
- Launch status explains when MelonLoader is building the game's first-run assemblies and reports when BTD6 continues startup.

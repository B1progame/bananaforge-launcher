# BananaForge 0.3.22

## MelonLoader version advice

- Recommends a stable MelonLoader version using the last locally verified BTD6 build and live metadata from official MelonLoader releases and BTD Mod Helper compatibility rules.
- Shows whether the game Unity build was detected, the latest stable release, source check time, and the evidence behind the recommendation.
- Keeps the known-good v0.7.3 recommendation for the verified Unity 6000.3.23f1 build; warns when an unverified newer stable exists or the game build cannot be identified.
- Does not use AI guesses or install nightly versions automatically. Network failures keep the last known-good recommendation visible.

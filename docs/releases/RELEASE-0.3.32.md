# BananaForge 0.3.32

## Animated update progress

- Shows real download percentage and transferred size while BananaForge downloads a desktop update.
- Adds a checksum verification phase before the installer can run.
- Shows Steam-to-managed-copy sync progress in Settings, including copied-file counts when available.
- Adds GSAP easing and a moving indeterminate state, with reduced-motion support and cleanup on completion or failure.

# BananaForge 0.3.20

## Fixes

- Windows Error Reporting crash signatures are matched to the configured BTD6 executable and shown with an actionable Game logs notification.
- MelonLoader 0.7.4 nightly fail-fast crashes are identified as loader failures instead of being misattributed to a mod.
- Setup and runtime status recommend the verified MelonLoader v0.7.3 stable build for BTD6 Unity 6000.3.23f1.
- Windows crash reports now appear in the Game logs list alongside Unity, MelonLoader, and launcher logs.
- Crash notifications can open Game logs directly.
- Renderer crash recovery and mod compatibility notifications from 0.3.19 remain included.
